# 이미지

FinMATE(oh-my-finance)와 같은 3D 클레이 톤의 일러스트다. 색은 토큰의 남색(`--primary`)·황토(`--accent`)·종이색에 맞췄다. 사람이 Figma AI 이미지 생성으로 만들고 고른 뒤 배경을 투명하게 따서 넣었다. 그림 안에 글자·숫자·로고는 없다.

| 파일 | 쓰는 곳 | 내용 |
|---|---|---|
| `capital-desk.webp` | 홈 배너 1(입문 과정) | 장부 모양 건물·계단에서 공부하는 사람들 |
| `capital-calculator.webp` | 홈 배너 2(계산기) | 계산기와 원금↑·이자↓ 회차 막대, 출력된 회차표 |
| `capital-sandbox.webp` | 홈 배너 3(모의 여신), 가입 | 자동차 옆 상담 창구, 시계·넘어가는 달력 |
| `capital-branch.webp` | 로그인 | 불 켜진 지점 건물로 들어가는 사람 |

- 크기 1200×800, WebP(알파 포함). 원본 PNG(1536×1024)는 Figma 파일 "CapiMATE 이미지"에 있다.
- 바꿀 때는 같은 이름·같은 비율로 덮어쓴다. 그림 속에 가짜 수치·문구를 넣지 않는다.
